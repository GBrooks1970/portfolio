- **`source.commit` is the document's last-change commit** (`13d102a…`), not the repository head at refresh time, which was LAND-12's

## Durable lessons

- Prove a regeneration recipe against the *old* inputs before applying it to the new ones: it must reproduce the existing artefact exactly.
- A snapshot of a private document goes stale silently. The Learning Paths snapshot was stale from the moment #289 merged, and nothing could
  have flagged it. Refreshing it belongs in the checklist for any edit to the source document.
- An external-URL check can fail on a transient 5xx from GitHub itself; re-run before treating it as a regression.
