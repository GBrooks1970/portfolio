## Durable lessons

- The refresh script's `--check` exits 1 before a refresh and 0 after it, so it is a usable pre- and post-condition for a snapshot refresh.
- Text rendered with CSS `text-transform` reads differently from its source in `innerText`; match it case-insensitively in browser checks.
- A new source table (section 10) needed no change to the generator, the pinned test counts or the page's link set, because the source already wraps tables in scroll regions.
