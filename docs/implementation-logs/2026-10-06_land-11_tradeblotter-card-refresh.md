## Durable lessons

- The card had lagged because nothing generates its summary from the project's own backlog. The gates
  check membership, roles and generated output, not whether the copy is still true, so card text needs a
  deliberate refresh when a project's state changes.
- Registry `notes`, the landing summary and the project's own README can all drift independently. For
  TradeBlotter, the repository's backlog and changelog were the current source.
- The external-URL gate cannot be run from every environment; a 403 from a proxy is not evidence about
  the links.
