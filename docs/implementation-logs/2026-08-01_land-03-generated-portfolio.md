## Decisions

- Commit a generated registry lock with full source provenance. This makes local generation
  reproducible without duplicating registry authority or requiring network access for visitors.
- Keep the site generator dependency-free; require PyYAML only when extracting a new lock from an
  exact `portfolio-prompts` Git commit.
- Generate the entire deployable HTML file from a template and data rather than maintaining
  hand-edited regions inside `index.html`.
- Make `NeoCognitus70/portfolio-prompts` public after a redacted repository/history/log review so
  the required methodology link works for unauthenticated visitors. Secret scanning, validity
  checks and push protection were enabled immediately afterward.

## Failures and recovery

- The first render required every template token exactly once, but the lower-case showcase count
  deliberately appears in metadata and footer copy. Validation was narrowed so structural blocks
  remain single-use while derived count tokens may repeat; generation and tests then passed.
- The browser's full-page mobile screenshot stitch visually compressed and repeated content. Direct
  element bounds plus a normal viewport screenshot proved the actual 390px layout was 346px wide,
  single-column and overflow-free.
- The methodology repository initially returned 404 to unauthenticated visitors because it was
  private. A full redacted history/content/issue/comment/Actions review found no credential blocker;
  owner-approved public visibility restored the link, and all 24 external URLs then returned 200.

## Durable lessons

- A generated registry lock can preserve exact upstream provenance and offline determinism without
  turning the landing repository into the authority for membership or roles.
- Count-bearing prose must use repeatable generator tokens; structural HTML insertion points should
  remain unique.
- Full-page stitched screenshots are not authoritative for very tall mobile pages; pair a normal
  viewport capture with measured DOM bounds and overflow checks.
- Public-link validation must be unauthenticated. An owner-authenticated GitHub session can hide a
  broken public destination.
