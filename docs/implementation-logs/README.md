# Implementation Logs

This directory contains immutable, task-level records of completed development.

- Create one Markdown file per completed backlog item or tightly coupled delivery unit.
- Name it `YYYY-MM-DD_<backlog-id>_<short-description>.md`.
- Start from [`../templates/implementation-log.template.md`](../templates/implementation-log.template.md).
- Record exact commits, pull requests, validation and Pages runs.
- Do not rewrite an old log to change history. Add a dated correction or a new log that references
  the earlier record.

Planning belongs in `docs/backlog.md`; resumable evidence belongs here.
